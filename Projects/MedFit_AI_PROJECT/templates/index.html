How MedFit AI Works

MedFit AI follows a Retrieval-Augmented Generation (RAG) pipeline, combining semantic search, vector databases, and Large Language Models to provide reliable healthcare information from a trusted knowledge base.

01

User Query

Users enter medical questions, sports injury concerns, nutrition advice, physiotherapy exercises, yoga guidance, or use built-in healthcare tools such as BMI and Water Intake calculators.

02

Query Embedding

The user's question is converted into a dense vector using the BGE Small English Embedding Model, enabling semantic understanding beyond simple keyword matching.

03

Semantic Search

ChromaDB performs similarity search on thousands of embedded medical documents and retrieves the most relevant healthcare information.

04

Knowledge Retrieval

The system gathers the top relevant content from structured JSON datasets and verified healthcare PDF documents covering medicine, sports injuries, physiotherapy, yoga, and nutrition.

05

Prompt Construction

LangChain combines the retrieved information with a carefully designed prompt, ensuring the language model answers only from the retrieved context.

06

AI Response Generation

The Groq-powered Llama 3.3 Large Language Model generates an accurate, context-aware response while avoiding hallucinations outside the available knowledge base.

07

Healthcare Tools

When appropriate, MedFit AI provides personalized assistance using integrated tools including the Body Mass Index (BMI) Calculator and Daily Water Intake Calculator.

08

Reliable Results

Users receive a clear, structured healthcare response. If relevant information is unavailable, MedFit AI honestly states that the answer is not present in its knowledge base.

Built for Safety and Accuracy

MedFit AI is engineered using Flask, LangChain, ChromaDB, HuggingFace Embeddings, and Groq Llama 3.3. By enforcing Retrieval-Augmented Generation, answers remain grounded strictly within approved reference texts.
